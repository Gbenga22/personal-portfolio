# Gbenga Ayiola — Personal Portfolio

Personal portfolio site for Gbenga Ayiola, with resume content, five project case studies, GitHub work, and contact details.

## Portfolio

The site lives in `artifacts/personal-portfolio` in the Replit workspace and is built with React, TypeScript, Vite, and Wouter.

## Showcase projects

The `projects/` directory contains five dependency-free prototypes:

- Market Street — local commerce snapshot
- Relay — care handoff timeline
- Komorebi — operations footprint calculator
- Common Ground — neighborhood decision tool
- Ledger Letters — newsletter writing surface

Open any project's `index.html` directly to try it. Each project also has its own README with the intended story and skills demonstrated.
